# HighOnTunes 🎵

Because every emotion deserves a soundtrack.

Built by Shweta Vare 🚀

## About The Project

HighOnTunes is an AI-powered music recommendation system that recommends songs based on mood and language preferences.

The application also includes a chatbot that understands user feelings and automatically suggests songs matching the detected mood.

This project combines Machine Learning, SQL, Gradio, and Hugging Face deployment to create a complete end-to-end music recommendation experience.

## Features

- 🎵 Mood-Based Song Recommendations
- 🌍 Language-Based Filtering
- 🤖 AI Mood Detection Chatbot
- 🗄️ SQL Database Integration
- 🎨 Interactive Gradio Interface
- 🚀 Public Deployment on Hugging Face

## Tech Stack

- Python
- Pandas
- SQLite
- Gradio
- Hugging Face Spaces
- Machine Learning
